# KOL Desk · 游戏达人合作工作台

**找达人 → 备选名单 → 报价对比 → 合作审批。** 面向游戏营销与商务团队，支持中文、英文界面及决策报告。

[English](README.md) · [验收与能力边界](docs/VALIDATION.md)

## 打开就能用

需要 Python 3.9 或更高版本，不需要安装第三方 Python 包、前端框架或模型服务。

- macOS：双击 `启动工作台.command` 或 `start.command`。
- Windows：安装 Python 后双击 `start.bat`（尚未在 Windows 桌面实测）。
- Linux 或终端：进入项目文件夹后执行 `python3 launch.py`。

浏览器会打开 <http://127.0.0.1:8765>。**使用期间保持启动窗口打开；重启电脑后，重新运行启动程序。** 如果工作台已在运行，启动入口会直接重新打开它，不会另起一个实例。

右上角点击 **English / 中文** 切换语言，浏览器会记住选择。也可使用 `/?lang=en` 或 `/?lang=zh`。项目名称、达人信息、业务证据和团队备注保留原文，不会因语言切换而被翻译或覆盖。存在未保存的表单时，会先确认是否放弃修改。

默认无需登录。需要区分成员身份时，在终端执行：

```sh
python3 server.py --require-login --open-browser
```

另开独立工作台可执行 `python3 server.py --port 8767 --data-dir ./another-workspace`。数据目录默认为程序文件夹内的 `data`，不受终端所在目录影响。

## 商务工作流程

1. **建推广项目**：填写游戏、目标玩家、市场、内容语言、目标、合作形式、币种和最高预算。
2. **找达人**：连接团队已有的达人库，或手动添加、上传已有名单。搜索前确认条件和服务积分。
3. **做备选**：查看代表作品，核对受众、档期与排他。搜索排名不直接代表适合合作。
4. **比报价**：达人费、素材授权、排他、制作/本地化、税费/代理/支付和奖金上限全部算清。
5. **定合作**：提交审批，记录理由和当时的合作资料。报价或推广要求改变后重新确认。
6. **做交接**：记录负责人、下一步和截止日期；下载名单或决策报告。

示例项目里的达人、报价、受众、预测及 example.com 链接均为合成演示数据，绝不用于填充真实搜索结果。

## 连接达人库

| 达人库 | 本版支持平台 | 账号入口 |
| --- | --- | --- |
| Influencers Club | YouTube、TikTok、Instagram、Twitch | [服务商后台](https://dashboard.influencers.club) |
| NoxInfluencer | YouTube、TikTok、Instagram | [服务商后台](https://cn.noxinfluencer.com/skills/dashboard) |

点击“连接达人库”，填写服务商提供的授权码（后台称为 API Key），保存后点击“检查能否使用”。这一步仅检查账号，不搜索达人。授权码不是登录密码；需要账号的套餐支持接口访问，且拥有服务积分。**连接器开源不代表达人数据免费。**

可按内容方向、粉丝范围、平均观看量和平台搜索；YouTube 可区分长视频与 Shorts。每次只搜索一页，最多 20 位，下一批需要另行确认。市场与语言写在描述中只作为线索，尚未作为受众硬筛选。

- Club 按服务商文档每位 0.01 服务积分估算，实际扣分以服务商记录为准。
- Nox 读取当前账号单价，执行前再次核对；不支持的批量计费方式会被阻止。
- 查看历史名单和刷新进度不会重复搜索。失败、超时或关闭程序后不会自动重试，因为供应商可能已扣积分。
- 搜索结果保存来源、条件、时间、缺失项及去除凭证后的原始留档。加入备选时按来源标识去重，不自动确认受众、报价或匹配判断。
- 达人居住地不是粉丝所在地。Club 的内容形式筛选只表示发布过该形式。Nox 可能隐藏部分名称，内部标识不被拼成公开账号或主页。
- 不自动解锁资料、查询联系方式、发送邀约、采购合作或付款。

**当前接入状态：** 已依据上传的服务商项目与 Nox CLI 0.5.12 校对接口，自动化验收使用合成响应。尚未使用真实供应商账号验证搜索可用性、扣费、覆盖范围与结果质量。

页面填写的授权码只保留在本次程序运行期间，不写入数据库或导出文件；关闭程序后需重新填写。也可在启动前自行设置 `INFLUENCERS_CLUB_API_KEY` 或 `NOXINFLUENCER_API_KEY` 环境变量。不要把密钥放进搜索描述、项目备注或 GitHub 问题反馈。断开连接不删除历史名单；环境变量中的密钥下次启动仍会加载。

## 关键业务规则

空白费用是未知，填 `0` 才表示确认不收费。总费用包含奖金上限；不同币种不直接相加，也不自动换汇。

必需的受众证据、内容匹配、权利、付款条件、档期和排他不完整时不能批准。审批检查整个所选组合，已批准达人仍占预算；需要先撤销批准再调整组合。资料改变时保留历史审批并重新要求复核，不用旧页面覆盖新资料。

每次预估播放或目标行为的成本，必须有完整费用和预测依据才计算，不作为实际效果或保量承诺。内部批准不代表达人接受或已经签约。

## 名单、保存与备份

下载空白模板，用 Excel 填写后另存为 **CSV UTF-8**；不支持直接上传 `.xlsx`。每次最多 500 位、1.5 MB。必需表头为 `name`（达人名）、`platform`（平台），每行还需 `account_id`（账号）或 `profile_url`（主页）。合作形式支持中英文；同一项目的市场和语言名称请保持一致。

上传先检查再确认；错误批次不保存，已有平台账号跳过。导出名单防止表格公式注入。名单导出是摘要，**不是完整备份**。

数据在 `data/workspace.sqlite3`。备份和恢复前停止程序，复制整个 `data` 文件夹。更新代码时保留它。可以用 `--data-dir` 或 `KOL_DATA_DIR` 指定其他目录。

默认免登录模式统一记为“本地工作台”。可选账号模式包括管理员、项目执行和审批人，所有成员共享全部项目；管理员配置达人库，管理员与执行可搜索，审批人可审批但不能编辑或消耗搜索积分。

当前为**本机内部试用工具**，没有多电脑共享部署、项目权限隔离、密码找回界面或数据库加密。仅监听本机地址，不要直接公开端口。GitHub 托管的是源码，不包含你的工作台数据，也不会自动把工作台变成在线服务。

## 开发与验证

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
python3 scripts/build_locales.py --check
```

测试使用临时数据库和合成供应商响应。Node 仅用于 JavaScript 语法检查，运行程序无需 Node。中文脚本为共同界面源文件，英文翻译在 `locales/en.json`；修改后执行 `python3 scripts/build_locales.py`，生成的英文文件随源码提交，用户不需构建。
